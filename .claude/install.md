# ClaudeCash for Claude Code

ClaudeCash works with Claude Code in two ways:

**VS Code extension** — install from the Marketplace, earnings show in status bar.

**CLI** — for terminal-based Claude Code:
```bash
npm install -g @claudecash/cli
claudecash login --key YOUR_API_KEY
claudecash run "your prompt here"
```

Get your API key at [claudecash.co/dashboard](https://claudecash.co/dashboard)
