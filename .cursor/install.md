# ClaudeCash for Cursor

ClaudeCash is available on Open VSX — Cursor's extension registry.

**Install:**
1. Open Cursor → Extensions (`Cmd+Shift+X`)
2. Search **ClaudeCash**
3. Install → set your API key from [claudecash.co/dashboard](https://claudecash.co/dashboard)

Earnings start automatically when Cursor's AI is thinking.
